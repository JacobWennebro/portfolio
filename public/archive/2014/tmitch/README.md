# Tmitch Studios site archive

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000/`.

The four pages, their displayed images, wallpaper, font, menu styling, and 2:20 audio track are local. The original Flash audio player was replaced with a native browser audio control. Twelve original image uploads named in the old page metadata are preserved under `assets/originals/`.

The Games page had an invalid image URL in the original HTML. Its image is restored from the same downloaded image used on the About page.
